# Coat color and pattern

Cat “orange / black / calico / cow” labels are **color or pattern**, not breeds.

## Classes and properties

- **CoatColor** `pets:CoatColor`
- **CoatPattern** `pets:CoatPattern`
- **hasCoatColor** `pets:hasCoatColor` — domain CompanionAnimal, range CoatColor (may be multiple)
- **hasCoatPattern** `pets:hasCoatPattern`
