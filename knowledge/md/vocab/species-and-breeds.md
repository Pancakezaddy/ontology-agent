# Species and breeds

Class hierarchy (asserted `rdfs:subClassOf` only):

- **CompanionAnimal** `pets:CompanionAnimal` — An animal kept as a companion in the household.
  - **Dog** `pets:Dog` — Domestic dog.
    - **Flat-Coated Retriever** `pets:FlatCoatedRetriever` — Gundog with a flat, dense coat. See [Vader](../animals/vader.md).
  - **Cat** `pets:Cat` — Domestic cat. Breed is not asserted for the named cats.
  - **Rabbit** `pets:Rabbit` — Domestic rabbit.
    - **Dutch rabbit** `pets:DutchRabbit` — See [Q](../animals/q.md).
    - **Rex rabbit** `pets:RexRabbit` — Short plush rex coat. See [Jules](../animals/jules.md).
