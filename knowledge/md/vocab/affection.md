# Affection methods

**AttentionForAffectionMethod** — capturing attention whose intended outcome is affection.

- **solicitsAffectionUsing** — the animal’s bid
- **prefersAffectionVia** — what works when a person gives affection
- **Anti-bids** (do not treat as invitations) — [antibids.md](antibids.md)

## Bid schema

Use these fields when adding or matching a cue:

| Field | Meaning |
| --- | --- |
| Initiator | Animal or person |
| Body region | e.g. belly, chin, cheek, head, back |
| Intensity | light / firm / vigorous |
| Looks like | Observable description |
| Not this | Easy confusion |
| Sequence | What comes before/after |
| Consent | Required invite vs always-ok |

## Discriminators (high-confusion pairs)

| Cue | Looks like | Not this |
| --- | --- | --- |
| Flopping | Side-flop / stretch near you | Loafing (feet tucked) |
| Loafing | Loaf + eye contact + teeth chitter (Q) | Flop |
| SittingAtDistance | Awkward sit apart (Lilo) | SittingClose |
| HeadBonk | Bonk after distance sit (Lilo) | Nudging |
| PresentingBelly | Belly offered; Salem gives it easily | Forced belly rub |
| BringingToyToPlay | Stevie drags wand to you | Vader bringing toy to go **outside** |
| BringingToyToGoOutside | Vader + Halloween cat toy | Play-wand request |
| CalledHandsomeBoy | Verbal praise Vader loves | — |
| UninvitedTouch | Any grab Q did not invite | Pets after flop/loaf bid |
